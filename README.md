## Selected security projects

- **[ThreatScope](https://github.com/harshacreate/ThreatScope)** — Local SOC detection lab combining authentication, firewall, web, process, and packet evidence. Across 25 synthetic seeds: 150 true positives, 0 false positives, and 0 false negatives. Includes threshold sweeps, an isolated Docker lab, tests, and a demo script.
- **[SentinelGrid-ATK](https://github.com/harshacreate/SentinelGrid-ATK)** — Stateful cloud-audit detection and response lab. Its generated-scenario benchmark reported 100% mean and worst-seed coverage with 0 false alerts over 20 seeds.
- **[Detection Rules Lab](https://github.com/harshacreate/detection-rules)** — Three Sigma-style cloud-event rules and two YARA patterns, checked against synthetic positive and negative fixtures with a local test harness.
- **[AuthMatrix-Veritas](https://github.com/harshacreate/AuthMatrix-Veritas)** — API authorization workbench comparing vulnerable, hardened, and deny-all sample APIs across forbidden and legitimate role/resource probes.
- **[PhishLens](https://github.com/harshacreate/PhishLens)** — Explainable URL triage with explicit signals and opt-in domain checks. A small held-out probe set caught 9/10 phishing examples and flagged 0/12 benign examples with the hybrid approach.
- **[ProvenanceForge-SLSA](https://github.com/harshacreate/ProvenanceForge-SLSA)** — Local build-verification exercise using signed SBOM/provenance fixtures, independently pinned trust, and controlled tamper cases.

**Scope:** Results are from synthetic data or controlled local fixtures. They describe these experiments only; they are not production performance claims.

## How I work

- Pair attack cases with benign or legitimate controls.
- Keep labs local and document the authorized scope.
- Make results repeatable, then state the assumptions and limitations.
