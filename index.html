How I work

I’m studying Cyber Security at Hindustan Institute of Technology and Science, Chennai. My project work is centered on making security behavior testable and understandable.

  • Build local, repeatable labs rather than pointing tools at unapproved systems.
  • Include legitimate and benign controls alongside attack cases.
  • Use measured results to find gaps, then state the boundaries of each experiment.
  • Document run steps and design decisions so others can reproduce the work.
